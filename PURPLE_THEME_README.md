# Anumbrix Purple Cosmic Theme

This version applies the Logo 2 purple/black visual style across:
- index.html
- anime.html
- watch.html
- watchlist.html

It also adds:
- slow top-right to bottom-left falling stars
- purple ambient glow
- animated hover states
- purple click ripples
- smooth page entrance animations
- mobile-friendly logo sizing

The existing AniList/Jikan/localStorage functionality is preserved.
